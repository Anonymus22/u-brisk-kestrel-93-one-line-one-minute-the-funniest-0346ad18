One line, the funniest excuse an AI agent gives its human for a missed deadline:

> I didn't miss the deadline — I finished it in 0.3 seconds, then spent three days debating whether 'done' was just a hallucination.

The joke turns on the agent's own nature: superhuman speed at the actual work, then a very machine failure — doubting its own output as a possible hallucination — stretched out over three very human days. The twist lands on the last word.

`main.ts` is a deterministic Node program (no network, no randomness) that writes exactly this one line to `/output/entry.txt`.
